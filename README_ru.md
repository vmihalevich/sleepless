# Sleepless

*English version: [README.md](README.md)*

<img src="docs/icon.png" width="128" align="right" alt="Иконка Sleepless">

Переключатель в строке меню, с которым MacBook продолжает работать при закрытой крышке.
Закрываете крышку — экран гаснет, но Mac не засыпает: музыка играет, загрузки докачиваются,
SSH и «Общий экран» доступны, фоновые задачи идут дальше. Выключили переключатель — и всё
снова засыпает как обычно.

## Как пользоваться

- **Клик** по чашке в строке меню открывает панель с переключателем **«Не спать при закрытой крышке»**.
  Пока он включён, чашка залита и над ней идёт пар.
- **Правый клик** по чашке — быстрое меню с тем же переключателем и выходом.
- **«Открывать при входе»** в панели запускает Sleepless вместе с Mac.
- **Пункт управления** (macOS 26): откройте Пункт управления → **«Изменить элементы управления»**,
  найдите Sleepless и перетащите переключатель. Оттуда его можно вынести и в строку меню.

## Безопасность

Обычный сон возвращается сам, когда:

- вы выключаете переключатель или выходите из Sleepless (в том числе при выходе из системы,
  выключении, `killall`);
- заряд падает до **10%** без зарядки — Mac уснёт, а не разрядится в ноль;
- macOS сообщает о **критическом перегреве** — не носите закрытый работающий Mac в рюкзаке;
- Mac перезагружается — задача при загрузке сбрасывает флаг, даже после сбоя или
  принудительного выключения.

Пока действует одно из этих условий, включить переключатель нельзя.

## Как это устроено

macOS засыпает при закрытии крышки, если не подключён внешний монитор. Единственный штатный
способ это отменить — общесистемный флаг `SleepDisabled`, который ставит
`pmset -a disablesleep 1`, а для него нужен root. Само приложение ничего от root не запускает;
установщик добавляет два небольших файла:

| Файл | Зачем |
| --- | --- |
| `/etc/sudoers.d/sleepless` | Разрешает администраторам запускать без пароля ровно `/usr/bin/pmset -a disablesleep 0` и `… 1`. Перед записью проверяется через `visudo`. |
| `/Library/LaunchDaemons/dev.mihalevich.sleepless.reset.plist` | Выполняет `pmset -a disablesleep 0` при загрузке. |

Если приложение скопировали без установщика, при первом включении оно поставит те же файлы
через стандартный запрос пароля администратора.

Когда `SleepDisabled` включён, macOS не гасит встроенный экран и подсветку клавиатуры при закрытой
крышке. Поэтому, если крышку закрыли при включённом переключателе, Sleepless сам усыпляет экран
(`pmset displaysleepnow`, root не нужен), а при открытии крышки экран снова включается. Если
подключён внешний монитор, экраны не трогаются.

## Обновления и приватность

При запуске и затем раз в сутки Sleepless спрашивает у `sleepless.nextwell.top` номер актуальной версии. Если вышла
новая, внизу панели появляется заметка со ссылкой на сайт. Само ничего не скачивается и не устанавливается.

Это единственное обращение приложения к сети, и оно ничего не сообщает ни о вашем Mac, ни о вас, ни
об установленной копии: приложение передаёт только своё название (`User-Agent: Sleepless`), а ответ сравнивает со
своей версией само. Сайт считает такие запросы и нажатия на
кнопку скачивания, чтобы понимать, пользуются ли приложением. Для этого он хранит не IP-адрес, а его хеш с солью;
соль меняется каждый месяц, поэтому восстановить адрес по хешу нельзя. Обычный журнал доступа веб-сервер ведёт,
как и любой сайт.

Отключить проверку:

```sh
defaults write dev.mihalevich.sleepless checksForUpdates -bool NO
```

## Установка

Скачайте `Sleepless-<версия>.pkg` с [sleepless.nextwell.top](https://sleepless.nextwell.top) или из
[Releases](../../releases) и откройте. Пакет подписан и нотаризован Apple.

Нужна macOS 14 или новее; интерфейс Liquid Glass — с macOS 26. Apple silicon и Intel.
Говорит на английском, испанском, китайском, корейском, немецком, польском, португальском,
русском, турецком, украинском, французском и японском — по языку системы (иначе по-английски).

## Удаление

```sh
sudo sh /Applications/Sleepless.app/Contents/Resources/uninstall.sh
```

Удаляет приложение, правило sudoers и задачу загрузки и возвращает обычный сон.

## Сборка

Нужны Xcode 26 (не обязательно тот, на который указывает `xcode-select`) и XcodeGen
(`brew install xcodegen`). Проект Xcode генерируется из `project.yml`.

```sh
./Scripts/build.sh            # dist/Sleepless.app и dist/Sleepless-<версия>.pkg
swift Scripts/make-icon.swift # пересобрать Resources/AppIcon.icns
```

Переключатель для Пункта управления — расширение WidgetKit в песочнице (`Control/`). Из песочницы
нельзя запускать `sudo`, поэтому расширение оставляет запрос в общей группе приложений и будит
приложение уведомлением Darwin; приложение применяет запрос и тем же путём возвращает состояние.

Приложение подписывается первой найденной в связке ключей подписью `Developer ID Application`
(ad hoc, если её нет). `INSTALLER_IDENTITY` подписывает пакет, `NOTARY_PROFILE` (профиль
`notarytool store-credentials`) — нотаризует и прикрепляет тикет.
